ONE DROP - Version 0.1 Release Notes

- Implementation of core gameplay mechanics (horizontal movement, jump, wall climb, wall jump).
- Implementation of Slide Dash (double tap left/right).
- First pass of lava-themed environment visuals.
- Integration of placeholder visuals for gameplay readability.

ONE DROP - Version 0.2 Release Notes

- Implementation of 3C improvements (Character, Camera, Controls).
- Camera update: static camera replaced by smooth follow camera with optional limits.
- Character feedback update: stronger soft-body style squash/stretch reactions in movement states.
- Controls update: keyboard + mouse + gamepad support improvements.
- Gameplay polish: anti-edge-stick collision handling and movement stability fixes.
- Gameplay readability update: improved visual contrast between safe paths and dangerous lava areas.
- Initial production setup for HUD/Menu pipeline (foundation stage).

ONE DROP - Version 0.3 (Gameplay Fix Pass - 2026-02-15)

- Movement tuning fix: added Rigidbody damping override and speed-aware acceleration so `moveSpeed` changes are immediately noticeable.
- Jump stability fix: ground detection now validates floor normals and uses a dedicated foot probe to prevent false grounded states on platform edges/undersides.
- Wall-jump spam fix: climb detach jump now triggers once per away-input transition and respects jump interval cooldown.
- Eyes tracking fix: googly eyes now follow Rigidbody movement/velocity for OneDropController2D, so eyes react when moving and jumping left/right.

ONE DROP - Version 0.4 (Combat + Enemy Pass - 2026-02-24)

- Enemy gameplay added: patrol movement with turn-at-boundary behavior, wait time at endpoints, and run animation control.
- Shooting gameplay expanded: OneDrop can fire bullets with cooldown, directional firing, and keyboard/gamepad input support.
- Combat effects added: muzzle flash, impact splash, and enemy vaporization effect on valid kill targets.
- Bullet visual polish: optional water-blob style bullet mesh/visual generation.
- Target filtering system updated in `OneDropAttack2D`:
- `bulletAttackableLayers`: layers that can be destroyed (recommended: Enemy).
- `bulletNonDestructibleLayers`: layers that can be hit but must never be destroyed (recommended: Wall/Ground/Platform).
- `bulletIgnoredLayers`: layers bullets pass through completely.
- Bug fix: walls/platforms no longer disappear with vaporization when bullets hit them.
- Architecture cleanup: bullet hit/destroy filtering is controlled from `OneDropAttack2D` runtime behavior for centralized combat rules.

ONE DROP - Version 0.5 (Water Resource + Death HUD Pass - 2026-02-25)

- New gameplay resource: OneDrop now has a water level (max water pool) that drains during actions.
- Drain actions implemented: movement over speed threshold, shooting, jumping, and sliding.
- New top-center HUD gauge added at runtime to display remaining water.
- HUD style update: transparent circular water fill effect with dynamic alpha based on remaining water.
- Combat integration update: shooting is blocked automatically when water is empty.
- Movement integration update: jump and slide actions consume configured water amounts.
- Death rule implemented: when water reaches 0, OneDrop evaporates and player control/combat are disabled.
- Death feedback added: vapor effect on player evaporation with optional prefab override.
