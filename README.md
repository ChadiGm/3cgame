## Description du jeu
ONE DROP est un jeu d'arcade 2D a theme lave, centre sur un personnage "goutte" agile. Le coeur du gameplay repose sur une boucle de plate-forme et de combat courte et lisible:
- Deplacements horizontaux, saut, escalade de mur et wall-jump.
- Slide dash (double-tap gauche/droite) pour l'esquive et la vitesse.
- Systeme de tir directionnel avec cooldown, impacts et effets de vaporisation.
- Ennemis patrouilleurs avec comportement de retour aux limites et animation de course.
- Ressource d'eau: une jauge se vide lors des actions (saut, slide, tir, vitesse) et bloque le tir a 0.
- Condition de mort: a 0 eau, le personnage s'evapore et perd le controle.
- Lisibilite visuelle renforcee: contraste securite/danger dans les zones de lave.
